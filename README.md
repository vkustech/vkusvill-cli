# vkusvill

**Русский** · [English](README.en.md)

![Карточка товара: манго Египет за 385 ₽](docs/screenshot.png)

Экспериментальный клиент ВкусВилла для терминала — один из примеров широкой палитры возможностей [официального MCP-сервера ВкусВилла](https://github.com/vkustech/vkusvill-mcp-server-manifest), открывающего новые форматы взаимодействия и персонализации.

Псевдографика поверх MCP: каталог, акции, рецепты, магазины и корзина, которую можно оформить на телефоне по QR-коду, а после авторизации — история заказов, любимый продукт и персональные предложения.

```bash
npx vkusvill                # интерфейс
npx vkusvill сырники        # сразу с поиском
```

## Требования

- Node.js 20+
- Терминал от 64×18 и 256 цветов, лучше 24 бита. Точно подойдут iTerm2, WezTerm, Ghostty, kitty, Windows Terminal и терминал VS Code.

## Что внутри

- **Каталог.** Поиск по мере набора, категории, подсказки, недавние запросы; пустой запрос — товары дня. Карточка справа: фото, цена, рейтинг, КБЖУ, состав с подсветкой сахара, добавок, глютена и лактозы.
- **Сортировка и фильтры.** Сортировки ВкусВилла и свои: цена за кг, белок на рубль, калории, скидка. Фильтры: без сахара, глютена, лактозы, добавок, пальмового масла; со скидкой, рейтинг от 4,8, белок от 10 г, до 150 ккал. Если фильтры отсеяли почти все, страницы догружаются сами.
- **Товар.** Галерея, диаграмма БЖУ, описание и все свойства. `[` `]` — соседние товары, `a` — аналоги.
- **Сравнение.** До четырех товаров рядом, лучшее значение в строке помечено.
- **Акции.** По карте, «от N штук», комбо-наборы; только ВкусВилл или все бренды.
- **Рецепты.** Поиск и фильтры: аллергены, время, сложность, способ готовки. Шаги и чек-лист ингредиентов, `+` кладет отмеченное в корзину.
- **Магазины.** Регион, город, метро, особенности, поиск по адресу, «открыт до 23:00». Карта точками Брайля с МКАД и Садовым кольцом: `z` — приблизить, `L` — все магазины фильтра.
- **Корзина.** Количество стрелками, итог, экономия, КБЖУ корзины; устаревшие цены сверяются сами. `p` создает ссылку и QR-код: корзина откроется в приложении ВкусВилла на телефоне, оплата и доставка там.
- **Профиль.** Избранное и история хранятся локально. Заказы, любимый продукт и «6 скидок» — после входа.

## Клавиши

Все работает с клавиатуры, в том числе в русской раскладке, и мышью. Вкладка, сортировки и фильтры запоминаются.

| Клавиша | Действие |
|---|---|
| `↑ ↓`, `j k` | по строкам: поиск, фильтры, список, кнопки |
| `← →`, `⏎` | по фильтрам и кнопкам в строке, нажать |
| `↑` у верхнего края | в шапку: `← →` по вкладкам и кнопке входа |
| `1`…`6`, `Tab` | вкладки |
| `/` | поиск |
| `+ −` | в корзину / убрать |
| `*` | в избранное |
| `s` `f` `g` | сортировка, фильтры, категория |
| `x` `X` | отметить для сравнения, сравнить |
| `b` | поиск по штрихкоду |
| `o` | открыть на сайте |
| `p` | в корзине — оформить и оплатить |
| `Ctrl+K` | палитра команд |
| `?` | все клавиши |
| `esc` | назад |
| `q` | выход |

## Команды

После `npm i -g vkusvill` доступны `vkusvill` и короткое `vv`; без установки — `npx vkusvill search …`.

```bash
vv search творог --sort price_asc   # таблица; --json — ответ как есть
vv deals --quantity
vv deals --personal                 # «6 скидок для меня»
vv orders                           # заказы за 30 дней
vv product 27695
vv barcode 4607167640050
vv recipes тыква
vv shops Речной вокзал
vv cart add 27695 2
vv cart link                        # ссылка и QR-код
```

## Вход

Персональное скрыто за авторизацией. ВкусВилл предоставляет доступ через кастомный OAuth.

1. Зарегистрируйте агента на [vkusvill.ru/oauth/registration/](https://vkusvill.ru/oauth/registration/) и отметьте «У моего сервиса нет публичного URI»: ВкусВилл подставит `http://localhost:3000/callback`.
2. `client_id` и `client_secret` придут на почту.
3. `vv login` или «войти» в шапке: введите их и подтвердите вход в браузере. Если порт 3000 занят, вставьте адрес, на котором остановился браузер.

Токен продлевается сам. `vv auth` — состояние и права, `vv logout` — выход с отзывом токенов, `VV_TOKEN` — готовый токен для CI.

Под капотом: authorization code + PKCE (S256); сервер авторизации находится через MCP (RFC 9728, RFC 8414) и должен быть https-адресом ВкусВилла; приемник слушает только 127.0.0.1. Refresh token одноразовый, поэтому продления из разных процессов идут по очереди через файл-блокировку.

## Где хранятся секреты

| Платформа | Секрет клиента и токены |
|---|---|
| macOS | связка ключей, «ВкусВилл в терминале» (служба `vkusvill-cli`) |
| Windows | `%APPDATA%\vv-cli\secrets.dpapi`, зашифрован DPAPI: прочитать можете только вы и только на этом компьютере |
| Linux с рабочим столом | Secret Service (GNOME Keyring, KWallet) через `secret-tool` из `libsecret-tools` |
| Linux по SSH, WSL, контейнеры | `auth.json` с правами 0600, как `~/.npmrc` у npm |
| CI | `VV_TOKEN`, на диск ничего |

Секреты попадают в хранилище через stdin, а не аргументами, которые видны в `ps`. В `~/.config/vv-cli/auth.json` — только id клиента, срок и права. Где лежат секреты, показывают `vv auth` и страница «Аккаунт». `VV_SECRETS=file|keychain|dpapi|secret-service` задает хранилище явно, `vv logout --forget` стирает все.

## Приватность и безопасность

- Сайт не нагружается: в простое запросов нет, списки сами догружают не больше 10 страниц подряд, фото грузятся только для того, что задержалось на экране.
- Запросы уходят только ВкусВиллу, аналитики нет. `User-Agent` называет клиента и версию: `VkusVill-CLI/1.2.3 (macOS arm64; Node.js 24.1.0)`.
- Токены уходят только на адреса ВкусВилла и не следуют за перенаправлениями. Секрет вводится только по запросу `vv login` или через stdin, флага для него нет: флаги видны в `ps` и остаются в истории оболочки.
- Текст из сети очищается от управляющих символов терминала и смены направления текста.
- Ссылки открываются только на https-адреса ВкусВилла и Яндекса, без оболочки.
- Заказы и персональные ответы на диск не кэшируются.
- Состояние — `~/.config/vv-cli/state.json` (0600): запись атомарная, поврежденный файл сохраняется рядом. Кэш — `~/Library/Caches/vv-cli` или `~/.cache/vv-cli`, до 300 МБ.

Флаги состава — эвристика, а не медицинская оценка.

## Как устроено

- `src/term` — свой движок терминала без зависимостей: буфер ячеек, вывод только изменений, без мерцания, truecolor с откатом на 256 цветов, мышь, вставка.
- `src/api.js` — JSON-RPC к `https://mcp.vkusvill.ru/mcp`: дисковый кэш и очередь с приоритетами. Не больше 4 запросов одновременно и 55 в минуту, фоновым — до 30. На 429 и 503 все запущенные копии ждут столько, сколько просит `Retry-After`.
- `src/image.js` — WebP через wasm (`@jsquash/webp`), без системных библиотек.
- Крупные цены рисуются заливкой ячеек и не рвутся при любом межстрочном интервале.

## Разработка

```bash
npm install
node bin/vv.js --no-splash
npm test                      # без сети: вывод, вход на моке, клавиатура, хранилище секретов
node test/snap.js 120 36      # снимки экрана → test/out/*.html
```

Окружение: `VV_TOKEN`, `VV_COLOR=256|truecolor`, `NO_COLOR`, `VV_NO_SPLASH`, `VV_CACHE_DIR`, `VV_CONFIG_DIR`, `VV_ENDPOINT`.
